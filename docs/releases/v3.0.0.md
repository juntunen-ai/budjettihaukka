# Budjettihaukka 3.0.0

Julkaistu 2026-09-29. Tämä on julkisen GitHub-repositorion ainoa julkaisu.

## Mitä julkaistaan

Avoin sovelluskoodi: React-käyttöliittymä, FastAPI-kuori, kirjautuminen,
Firebase-infra ja käyttöönoton estävä julkaisuskripti. Lisenssi on
GPL-3.0-only.

Julkinen data: `data/`-hakemiston viiteaineistot ja skeemakuvaukset.
Viranomaisten omat julkaisut pysyvät lähteen ehdoissa.

## Mitä ei julkaista

Analyysimoottori, lataajat, testit, ontologia, SQL, semanttiset
johdannaiset ja Streamlit-käyttöliittymä. Ne on lisensoitu erikseen
eikä niitä ole tässä repositoriossa eikä sen historiassa.

Aiemmat julkiset versiot on poistettu. Niitä ei voi enää ladata tämän
repositorion julkaisuista tai tageista.

## Tuotanto

Osoite https://valtion-budjetti-data.web.app jää entiselle
käyttöönotolle. Versiota 3.0.0 ei viedä tuotantoon, koska julkinen puu
ei sisällä analyysimoottoria.
