# Budjettihaukka 4.0.0

Julkisen repositorion toinen julkaisu, marraskuu 2026. Versio 4.0.0
julkaistaan sekä tässä julkisessa sovelluskuoressa että erikseen
ylläpidetyssä yksityisessä repositoriossa. Sitä aiempi julkinen julkaisu
on [3.0.0](./v3.0.0.md).

## Mitä julkaistaan

- **Sovelluskuori versioon 4.0.0.** Käyttöliittymän alapalkissa näkyy
  „Budjettihaukka v4.0.0”. Käyttöliittymä ohjaa käännösaikana asetettuun
  kanoniseen osoitteeseen (`VITE_CANONICAL_ORIGIN`), jotta
  uudelleenohjauskirjautuminen toimii selaimissa, jotka eristävät
  kolmannen osapuolen tallennustilan. Riippuvuuksien lukitustiedosto on
  päivitetty: re2js 2.10.0 korjaa tuotantoriippuvuuden haavoittuvuuden
  GHSA-gg6h-894w-4m9c, joka kaatoi CI:n audit-vaiheen. `firebase.json` estää myös juuriosoitteen välimuistin.
  FastAPI-kuoren versio on 4.0.0, ja `/v1/analyze` vastaa edelleen 501.
- **Vaihtoehtobudjetti 2027.** Sivu
  `frontend/public/liberaali-vaihtoehtobudjetti-2027.html` ja sen
  momenttiaineisto ovat nyt ensimmäistä kertaa julkaisussa, ja
  ylävalikossa on linkki sivulle.
- **Siivous.** Poistettu GitHub Pages -workflow, käyttämätön
  `api/client.py`, politiikan kasvujarru- ja velka tunnissa -analyysit
  viitedatoineen, Google Sheets- ja bq CLI -manifestit sekä
  vaihtoehtobudjettisivujen juurikopiot. Tarjoillut sivut ovat
  hakemistossa `frontend/public/`, ja 2027-sivun muodostin kirjoittaa vain
  sinne. Streamlit-asetukset ja -riippuvuudet poistettu.
- **npm audit -portti.** `npm audit --audit-level=high` korvattiin
  tarkistimella `scripts/check_npm_audit.py`. Se hylkää jokaisen
  korkean tai kriittisen löydöksen, jolle ei ole voimassa olevaa,
  vain kehitysriippuvuuksia koskevaa poikkeusta tiedostossa
  `frontend/npm-audit-exceptions.json`. Ainoa poikkeus on
  GHSA-fc5q-39xc-vjpf (picomatch, vain Viten kautta, 31.12.2026 asti),
  sama kuin yksityisessä repositoriossa. GitHub veti tiedotteen pois
  18.11.2026, joten poikkeus ei nyt vastaa mitään löydöstä ja tarkistin
  ilmoittaa sen poistettavaksi. Tarkistimen testit ajetaan muiden
  offline-testien kanssa.
- **Rajan testit.** `tests/test_public_release_safety.py` varmistaa, ettei
  analyysimoottori, datan käsittelyn kerrokset, staging-asetukset eikä
  MCP-palvelin ole julkisessa puussa.
- **Tieto MCP-palvelimesta.** README kertoo, miten ydinaineistoa käytetään
  julkisen MCP-palvelimen kautta.

## Julkinen MCP-palvelin

Luotettu ydinaineisto on minkä tahansa kielimallin käytettävissä ilman
kirjautumista osoitteessa
`https://budjettihaukka-mcp-524401221130.europe-west1.run.app/mcp`
(Streamable HTTP). Aineisto on Valtiokonttorin kuukausittainen talousarvion
toteuma 2006–2026, hyväksytty versio `core_20261116_v3`. Rajat ovat
yhteiset kaikille käyttäjille, 60 kutsua minuutissa. Tuloksissa on
pakolliset datan laatua koskevat huomiot.

MCP-palvelimen koodi ei kuulu tähän julkaisuun.

## Mitä ei julkaista

Analyysimoottori, MCP-palvelin, lataajat, ontologia, SQL, semanttiset
johdannaiset, datan käsittelyn testit, staging-asetukset ja tuotannon
julkaisuskriptit. Ne ylläpidetään erillisessä yksityisessä
repositoriossa, eivätkä ne ole tässä repositoriossa eivätkä sen
historiassa.

## Tuotanto

Tuotanto (https://valtion-budjetti-data.web.app ja MCP-palvelin)
otetaan käyttöön yksityisestä repositoriosta. Tätä julkista kuorta ei
viedä tuotantoon: `scripts/deploy_firebase.sh` kieltäytyy, koska puusta
puuttuu analyysimoottori. Julkisen julkaisun vihreä CI ei todista mitään
tuotannon tilasta.

## Tunnetut rajoitteet

- npm audit -poikkeus GHSA-fc5q-39xc-vjpf on tarpeeton, koska tiedote on
  vedetty pois. Sen voi poistaa molemmista repositorioista. Uudet korkeat tai kriittiset löydökset kaatavat CI:n
  kuten ennenkin.
- Viranomaisten luvut pysyvät lähteiden omissa käyttöehdoissa.
